# genieautocenter.com

The Genie Auto Center website, served by GitHub Pages at genieautocenter.com.

Don't edit these files by hand. The site is managed in Shop Desk
(Settings → Website) and built by `tools/siteexport/export.mjs` in the
shop-desk repo. The page updates itself: every visit loads the latest
prices, hours and specials the shop has published, so this folder only
needs rebuilding when the page's design changes.
